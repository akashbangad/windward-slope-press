# Windward Slope — press kit

A hand-painted, one-thumb downhill ride through a Swiss Alpine valley that turns into a wildlife photo safari.
Free on iPhone. No ads, no in-app purchases, no tracking. Plays offline.

**Downloads:** see the [latest release](../../releases/latest) — trailers (9:16, 16:9, 1:1), three 15-second
shorts, the App Store preview, App Store screenshots, social images and the app icon.
